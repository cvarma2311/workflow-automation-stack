# Pure Python Prefect Data Processing Pipeline

This project implements a large-scale data processing pipeline entirely in Python, orchestrated by Prefect. The core data generation, filtering, and joining logic are implemented as standalone Python scripts, leveraging **Polars** for efficient data manipulation and **Parquet** files for optimized storage. This approach ensures robust orchestration with detailed memory profiling.

The pipeline performs the following steps, orchestrated as separate Prefect tasks:
1.  **Generate Data:** Creates a Parquet file with 500 million records.
2.  **Filter Data:** Reads a Parquet file, filters it based on an ID, and writes the result to a new Parquet file.
3.  **Join Data:** Reads original and filtered Parquet files, joins them, and writes the result to a new Parquet file.

Each Prefect task is decorated with a custom process-level memory profiler. Additionally, the core data processing scripts are instrumented with the `memory_profiler` library for **line-by-line memory usage analysis**.

---

## Architecture

-   **`prefect-python-flow` (This Project):**
    -   **Python Data Scripts (`generate_data.py`, `filter_data.py`, `join_data.py`):** Standalone Python scripts that perform the core data processing using **Polars**. These scripts are decorated with `@profile` from the `memory_profiler` library for line-by-line analysis.
    -   **Python Conductor (`flow.py`):** Defines the Prefect workflow (`@flow` and `@task`). Each task launches one of the data processing scripts as a subprocess.
    -   **Memory Profiler (`profiler.py`):** A Python decorator using `psutil` to log overall process memory (RSS, VMS, Peak) and time metrics for each Prefect task.
    -   **Ansible Setup (`ansible_setup/`):** An Ansible playbook to automate the installation of Python, pip, Prefect, psutil, **Polars**, and **PyArrow**.

## How to Run the Pipeline

Follow these steps to set up the environment using Ansible and then run the Prefect workflow.

### Step 1: Set Up the Environment

The provided Ansible playbook will install Python, pip, Prefect, psutil, Polars, and PyArrow.

1.  **Navigate to the Ansible directory:**
    ```bash
    cd prefect-python-flow/ansible_setup
    ```

2.  **Run the playbook:**
    ```bash
    ansible-playbook -i inventory.ini setup_environment.yml
    ```
    If you're on Linux, you might be prompted for your `sudo` password as it needs to install system packages. For macOS, Homebrew installations run without `sudo` (ensure `become: yes` is removed from the playbook if you encounter issues).

### Step 2: Run the Prefect Flow

Once the environment is set up, you can execute the Prefect workflow.

1.  **Navigate to the project root:**
    ```bash
    # From the repository root
    cd prefect-python-flow
    ```

2.  **Start the Prefect server (optional but recommended):**
    ```bash
    prefect server start
    ```
    Keep this terminal window open. Open your browser to the URL it provides (usually `http://127.0.0.1:4200`) to monitor the flow.

3.  **Run the flow (in a NEW terminal if Prefect server is running):**
    ```bash
    python3 flow.py
    ```

### What to Expect

-   A `data/` directory will be created in the project root to store the output files.
-   The Python script will start, and you will see logs from Prefect as it begins executing the flow.
-   Prefect will trigger each task (`generate_data_task`, `filter_data_task`, `join_data_task`) sequentially. Each task will execute its corresponding data processing script.
-   **Warning:** The `generate_data_task` will create a very large file (~1-2 GB Parquet) and will take some time, depending on your system's performance. It will also consume significant RAM while constructing the Polars DataFrame.
-   **Memory Profiling Logs:**
    *   The custom `profiler.py` will output **overall process memory (RSS, VMS, Peak)** and duration for each Prefect task.
    *   Within the logs for each task (specifically the `INFO` logs from the subprocess), you will see the **detailed line-by-line memory profiling output** generated by the `memory_profiler` library within the data processing scripts. This will look like:
        ```
        Line #    Mem usage    Increment  Occurrences   Line Contents
        ============================================================
            10     40.0 MiB     40.0 MiB           1   @profile(stream=sys.stdout)
            11                                        def my_function():
            12     50.0 MiB     10.0 MiB           1       x = [1] * (10 * 1024 * 1024)
            ...
        ```
-   Upon completion, you will find `500m_records.parquet`, `filtered_records.parquet`, and `joined_records.parquet` files in the `prefect-python-flow/data/` directory.
